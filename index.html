🔒 Autenticação e Banco de Dados (Firebase)

Isso configura login de verdade (criar conta, entrar com Google, recuperar senha) e um banco de dados real, com seus dados vinculados à sua conta e sincronizados automaticamente entre computador e celular. Usa o Firebase (do Google) — você precisa de um projeto gratuito seu, eu não tenho como criar um por você.

  1. Crie um projeto grátis em console.firebase.google.com
  2. No menu, vá em Authentication → Sign-in method → ative "E-mail/senha" e "Google"
  3. Vá em Firestore Database → Criar banco de dados (modo produção)
  4. Nas regras do Firestore, cole exatamente isto (isola os dados por usuário): 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
  5. Nas Configurações do projeto (⚙️ no menu) → role até "Seus aplicativos" → crie um app da Web → copie o bloco firebaseConfig = {...} e cole abaixo
